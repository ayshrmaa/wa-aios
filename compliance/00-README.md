# Compliance Document Set

Five documents, built once, reused for every client. No client is onboarded without all five in place.

**These are drafts, not legal advice.** Every one requires review and sign-off by a Swiss-qualified
lawyer before a client signs it or a call is recorded. Swiss data protection (revDSG, in force since
September 2023) and Art. 179ter of the Swiss Criminal Code both bear on the AI Receptionist. Get them read.
